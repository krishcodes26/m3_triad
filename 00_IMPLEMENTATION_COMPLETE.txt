1. ✅ XP SYSTEM
   - Three independent XP wallets (Mind, Muscle, Money)
   - Lifetime XP calculation (sum of all vectors)
   - Progressive level curves
   - Tier progress tracking
   - Per-vector XP rewards

2. ✅ VECTOR LEVELS (Mind, Muscle, Money)
   - Individual levels 1-30+ per vector
   - Progressive thresholds (500 XP at Lv2, 11,700 at Lv10, 43,700 at Lv20)
   - Accurate tier progress calculation
   - Independent from other vectors

3. ✅ CHARACTER LEVEL
   - Based on cumulative lifetime XP
   - Separate curve from vector levels
   - 45,000 XP ≈ Level 23 (example)
   - Tier progress toward next level

4. ✅ RANK SYSTEM (8 tiers)
   - E: Novice (Lv 1+, 0 XP)
   - D: Apprentice (Lv 20+, 50K XP, Lv 10+ vectors, 60% harmony)
   - C: Warrior (Lv 20+, 100K XP, Lv 15+ vectors, 70% harmony)
   - B: Elite (Lv 30+, 65K XP, Lv 25+ vectors, 75% harmony)
   - A: Master (Lv 45+, 150K XP, Lv 35+ vectors, 80% harmony)
   - S: Grandmaster (Lv 60+, 250K XP, Lv 45+ vectors, 85% harmony)
   - SS: Legend (Lv 75+, 400K XP, Lv 55+ vectors, 90% harmony)
   - SSS: Mythic (Lv 90+, 600K XP, Lv 65+ vectors, 92% harmony)

   KEY FEATURE: Rank promotion requires VECTOR STABILITY, not just high XP

5. ✅ TRI-VECTOR HARMONY
   - Formula: (min_score × 0.4) + (avg_score × 0.6)
   - Ranges 0-100%
   - Scores normalized to 0-100 scale (capped at Level 30)
   - Effect: Gates rank eligibility, prevents one-vector domination
   - Non-destructive: low harmony doesn't delete XP

6. ✅ XP REWARD SYSTEM
   - 20+ configurable reward rules
   - Mind: Focus (+15), Reading (+20), Deep Work (+40), Study (+30)
   - Muscle: Workout (+50), PR (+75), Protein (+40), Sleep (+25)
   - Money: Daily Action (+30), Client Milestone (+60), Revenue (+100)
   - Habits: Protocol (+15 configurable per habit)
   - Missions: Task (+50), Milestone (+120)
   - Per-rule configuration: base XP, cap scope, verification level, cooldown

7. ✅ BADGE SYSTEM
   - 6 example badges with progression framework
   - Single-vector and cross-vector badges
   - Tiered badges (Tier I, II, III)
   - Unlock conditions and reward XP
   - Examples: Deep Work Monk, Century Press, Consistent Striker, etc.

8. ✅ DASHBOARD INTEGRATION
   - Character Status card: Level, Rank, Harmony breakdown
   - Tri-Vector cards: Real vector levels, today's XP, tier progress
   - Lifetime XP Summary: Total + per-vector breakdown
   - Real data fetched from Supabase
   - Auto-refresh every 30 seconds
