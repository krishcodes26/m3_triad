# M3 Triad — Open Questions and Decisions Log

These questions are intentionally visible. Claude must not silently invent answers.

## Product and terminology
- [ ] Is the consumer-facing product name **M3 Triad**, **LIFE RPG**, or another name?
- [ ] Is “Mission” the canonical term, with “Quest” as flavour copy, or vice versa?
- [ ] Is Character/Profile one destination or two?
- [ ] Are Mind, Money and Muscle always the only vectors?

## XP and progression
- [ ] What earns XP in each vector?
- [ ] What is the formula for overall character XP?
- [ ] Are vector levels independent from overall level?
- [ ] What are the exact level thresholds and rank names?
- [ ] Are XP awards reversible? What happens when a task is reopened?
- [ ] How are duplicate events and imported records prevented from awarding XP twice?
- [ ] Can users manually assign vector attribution, and what prevents abuse?

## Missions and tasks
- [ ] Can one mission span multiple vectors?
- [ ] How is mission progress calculated?
- [ ] Can tasks recur?
- [ ] Are milestones mandatory?
- [ ] What happens when a deadline passes?

## Habits
- [ ] How are streaks calculated across timezone changes?
- [ ] Are grace days, rest days or pause windows supported?
- [ ] What exactly does “Momentum Protection” / “Counter-Action” do?

## Workout
- [ ] Exercise catalogue and custom exercise support?
- [ ] Which set types are supported?
- [ ] How is tonnage calculated for bodyweight, unilateral and assisted exercises?
- [ ] How are PRs detected?
- [ ] Is workout data manually entered or synced from another service?

## Nutrition
- [ ] What is the food data source?

- [ ] Are calories/macros manually entered, imported or both?
- [ ] Which micronutrients are in scope?
- [ ] What disclaimers and privacy requirements apply?

## Money

- [ ] Are bank/account integrations planned?
- [ ] Which currencies and regions must be supported?
- [ ] What data is private by default?

## Data, privacy and commercial
