║                        DATA FLOW & XP PROGRESSION                              ║
╚════════════════════════════════════════════════════════════════════════════════╝

User performs action:
  │
  ├─→ Complete Task          → XP_LEDGER entry (mind/money/muscle)
  ├─→ Check Habit            → XP_LEDGER entry + adherence tracking
  ├─→ Log Workout            → XP_LEDGER entry (muscle) + PR detection
  ├─→ Log Meals              → Nutrition tracking (no auto-XP yet)
  ├─→ Complete Focus Session → XP_LEDGER entry (mind)
  │
  └─→ XP_LEDGER accumulates
      │
      ├─→ VECTOR_PROGRESS updates (level/xp per vector)
      ├─→ CHARACTER_PROGRESS updates (overall level/rank)
      └─→ ACHIEVEMENTS checked (badges unlocked)
           │
           └─→ USER_ACHIEVEMENTS created
